# Git

- **NUNCA** faça commit, push, pull, merge, rebase, reset, revert, force push ou troca de branch sem autorização explícita.
- Não use `git reset --hard`, `git clean -fd` ou comandos destrutivos sem autorização.
- Quando solicitado a trabalhar somente localmente, ignore o remoto.
- Antes de qualquer operação Git autorizada, revise `git status` e `git diff`.
