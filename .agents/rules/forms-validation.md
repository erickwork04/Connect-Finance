# Formulários e validação

- Use Zod para validação quando a área já seguir esse padrão.
- `defaultValues` de formulários de edição devem refletir os valores atuais do registro.
- Não transforme valores silenciosamente.
- Campos monetários devem preservar precisão.
- Diferencie claramente valor exibido, valor do formulário e valor persistido.
