# Execução

- Investigue a causa raiz antes de aplicar workaround.
- Não altere arquivos fora do escopo sem necessidade.
- Preserve funcionalidades existentes.
- Se encontrar regressão causada por atualização de dependência, adapte o código à API atual em vez de mascarar o problema.
- Rode testes aplicáveis após alterações relevantes.
- Rode lint e build antes de considerar uma tarefa concluída.
- Não pare entre etapas apenas para pedir confirmação, salvo risco de perda de dados, mudança destrutiva ou decisão arquitetural importante.
- Alterações de frontend devem incluir validação funcional e responsiva antes de serem consideradas concluídas.
