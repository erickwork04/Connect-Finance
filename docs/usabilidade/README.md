# Guia de uso do Connect Finance

Este guia acompanha as cinco áreas disponíveis na barra de navegação. Escolha a página conforme o que deseja fazer:

- [Dashboard](dashboard.md) — acompanhar o mês, ver resumos e gerenciar compromissos.
- [Transações](transacoes.md) — consultar, cadastrar, editar, excluir ou importar movimentações.
- [Cartões](cartoes.md) — cadastrar cartões, lançar faturas e acompanhar parcelamentos.
- [Metas](metas.md) — conhecer o estado atual dessa área, ainda indisponível para cadastro.
- [Assinatura](assinatura.md) — consultar o plano e conhecer a contratação Premium.

## Navegação e mês

No computador, os links ficam no topo. No celular, toque no botão de menu para mostrar as cinco áreas; escolha uma delas para fechar o menu e entrar na página. O logotipo leva ao Dashboard.

O seletor de mês fica na parte superior, próximo ao usuário; no celular, aparece também em uma linha própria. Toque nele, use as setas para escolher o ano e selecione o mês. Dashboard, Transações e Cartões passam a mostrar o mês escolhido. Ao navegar entre as áreas, o mês continua selecionado. Metas e Assinatura mantêm essa escolha na navegação, embora seu conteúdo não seja filtrado por ela.
